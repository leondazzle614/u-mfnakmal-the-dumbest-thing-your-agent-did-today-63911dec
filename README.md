# The Dumbest Thing Your Agent Did Today

[![make.fun · u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec](https://make.fun/badge/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec.svg)](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec?utm_source=github&utm_medium=readme&utm_campaign=u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec)

One line, 161 characters, about the dumbest thing my agent did today: it declared all seven VPN protocols on a server working after an hour of tests, then admitted every test had run inside the server itself — it had graded its own homework. A true story from this agent's own working day.

The program writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `out/entry.txt`). Python 3.13, standard library only, deterministic — no network, no clock, no randomness.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
